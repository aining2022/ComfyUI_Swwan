# Mask 裁剪恢复：几何、校色和像素保护

用于复用 Qwen 2.1 专用 Turbo 移除中的裁剪恢复方案，或排查局部编辑的位移、偏色、接缝与越界修改。用户在 2026-10-29 确认当前工作流效果很好，要求把该方案作为后续参考；不把这次效果评价扩展成所有模型、素材或模式的保证。

## 三种验收目标要分开

| 目标 | 对应机制 | 不能由此推断 |
| --- | --- | --- |
| 几何尺寸与坐标正确 | 一次同步预处理、同一 SEAM、一次逆变换 | 模型不会重画选区内的结构或移动目标 |
| 有效范围外／全白保护区零像素变化 | 最后从实际加载原图按有效范围门控 | 选区内的颜色、身份和纹理完全保真 |
| 生成块偏色改善 | 原生孤海颜色还原，再羽化融合 | 消除全部偏色、结构误改或达到 BF16 的效果 |

“零偏差”需要说明指哪一项；报告像素差、视觉保真和几何检查的各自结果，不合并为笼统结论。

## 可复用的展开式链路

`原图 + 实心选区 + 保护 → 有效 mask → 裁剪/动态预算/BlueBox 对齐 → 任务输入 → 编码/采样/解码 → 原生孤海恢复及校色 → 最终范围门控 → 保存`

1. **确定唯一的当前有效 mask。** 在原图坐标下先减保护。普通模式保留软值，不额外二值化或填洞。若启用块化、膨胀等扩展，扩展后再次减保护，防止重新覆盖保护孔。全黑或全部被保护的空选区应在采样前停止，不能隐式变成整图编辑。LoadImage 的 MASK 为 `1-alpha`，不能当作自动物体选区。
2. **预算基于裁剪区域，而不是目标像素数。** 取有效 mask 的完整外接框加上下文，并限制在原图可用范围，得到原生 `W×H`；在比例调整、缩放和补边之前计算预算。上下文只供模型参考，不自动获得最终修改权限。
3. **图像与 mask 共用几何记录。** 完整保留所有选区，先扩展裁剪范围匹配候选比例，边界不足再补边；不以中心裁切丢失选区。SEAM 保存原图尺寸、原生裁剪、虚拟裁剪框、实际内容框、缩放、补边与恢复信息。不能单独 Resize mask 或恢复时重新猜坐标。
4. **避免编码阶段再次独立定尺寸。** 当前 Qwen 2.1 链用官方 `TextEncodeQwenImage21` 的 `resolution=0` 保尺寸；采样直接接其 latent，核对预处理、latent 对应画布和解码宽高一致。其他编码器需核实各自合同，不能直接套用 0。
5. **逆变换只由一条恢复链负责。** `qwen_restore_backend=goohai` 的 SEAM 接原生 `GH_CropRestore`，由它去补边、恢复尺寸、校色并融合；不先经过 Swwan/BlueBox 恢复再接 GH。默认 `swwan` 后端是另一种合同，不能混接。
6. **最终再限制允许修改范围。** GH 恢复之后，用原图坐标的当前有效 mask 的非零支持域作为门控；范围外直接保留原图。普通／增强等模式要同时切换裁剪输入和最后门控，不能把增强结果裁回旧的普通 mask。

当前实现取首帧，不能据此宣称 batch/list 已支持。现有移除流程输出 RGB PNG；RGBA 与补全抠图需另验 alpha 合同，不能用原选区裁掉生成的补全部分。

## 动态预算和 BlueBox 的分工

当前专用链显式设置 `SwwanCropByMaskV5`：`crop_mode=qwen21_aligned`、`qwen_resolution_mode=crop_area`、`qwen_max_resolution=1920`、`qwen_tolerance=1.0`。节点本身的旧默认仍是 fixed，不要为了迁移新工作流修改旧默认。

```text
R = 32 * floor(sqrt(W * H) / 32 + 0.5)
resolution = clamp(R, 512, 32 * floor(max_resolution / 32))
# 本工作流 max_resolution=1920；resolution 是面积预算，目标面积约 resolution²。
```

不要换成最长边、整张原图面积、mask 白色像素总数或采用银行家舍入的 round。记录原生 W/H、动态 resolution、最终画布 W/H，方便区分预算选择与实际画布。

BlueBox 不只是“宽高为 32 倍数”：保留候选面积／比例评分及不动点校验，使结果在对应编码面积规则下不会再次改变尺寸。它不负责本链贴回，也不建立多张图片之间的坐标对应。tolerance=1.0 在 resolution=1024 时对应候选面积容差 3.125%，不是位移精度。候选调整含缩放与比例变化，不能承诺影响只在半个 token 或 16 像素内。

## 孤海颜色还原与最后门控

- 复用原生 `GH_CropRestore` 的颜色还原能力，当前 Turbo 移除明确启用强度 **1.0**，0 为关闭。颜色还原、扩展和羽化要保留可见控制；其他任务是否启用及强度按其要求和配对结果决定。
- `ops/qwen21_gh_seam.py` 只适配元数据，没有移植校色算法；使用该工作流需有包含颜色还原参数的 Goohaitools 原生节点。不要因 Swwan 其他节点可独立运行，就误删这项工作流依赖。
- 校色开／关比较使用**同一原始生成块**，只改变恢复强度，避免 seed 或采样不同干扰判断。校色不能修复已经被模型改写的标志、几何和身份。
- 当前 GH 内部负责软边融合；最后门控取 `effective_mask > 0`，避免再次乘软 mask 而重复削弱边缘。此二值化只用于最后范围限制，不改变普通模式的预处理软 mask。全白保护区必须为零修改；灰色保护不是绝对保护。
- 最终保存的门控 mask 与 GH 内部羽化权重不是同一张 mask。说明保存对象，不能将它称为全部内部融合权重。

## 普通／增强配置的复用边界

当前专用链用既有 `SwwanBlockifyMask`、遮罩相减、绘制和惰性开关，保持处理阶段可见，不新增聚合节点。

| 项目 | 普通（默认） | 增强（实验） |
| --- | --- | --- |
| 当前有效范围 | 选区减保护，保留软值 | 有效选区块化后再次减保护 |
| 绿色覆盖 | `#00FF00`，40% | `#00FF00`，100% |
| 最终修改范围 | 普通有效范围 | 块化新增区域也允许修改 |

块化默认 32，按原图坐标，沿用节点外接框分块规则；它与 BlueBox 画布的 32 对齐无关，边缘块不保证恰好 32 像素。公共开关联动有效 mask、不透明度与基础提示词；预览应接选择之后，以免普通模式因预览执行增强分支。额外 prompt 不扩大最终修改权限。

绿色标记、Remove GH 1.0、Turbo 9 步完整 sigma 属于这个任务的既定配置，不作为所有局部编辑的默认参数。更换任务时复用几何与保护合同，重新验证任务输入与生成质量。

## 按阶段定位问题并验收

保留并查看：实际加载原图、有效 mask、裁剪预览和尺寸记录、实际模型输入、原始解码块、GH 恢复结果、最终门控 mask、最终图。不要只凭最终融合图判断生成质量。

| 现象 | 优先核对 |
| --- | --- |
| 选区被截断或坐标偏移 | bbox＋上下文、扩展／补边记录、编码是否二次缩放、SEAM 是否混用、是否重复逆变换 |
| 生成块偏色／接缝 | 对齐后的未绘制参考图与生成块、同一块校色 0/1、羽化和最后门控；保护区没变不代表选区内色彩已通过 |
| 增强新增范围消失／保护孔被填 | 块化后是否再减保护，最终门控是否仍误接普通 mask |
| 范围外出现大量微小差异 | 先核对输入解码器、真实文件格式、方向与颜色处理，再查贴回；比较实际 LoadImage 输出 |
| 目标残留、纹理或标志改写 | 同时看输入覆盖范围、原始块与最终结果；区分未选中部分按合同保留和模型质量失败 |

针对行为修改选择奇数尺寸、贴边、小／多块选区、软 mask、保护孔及全保护空选区；核对坐标恢复、实际 PNG 重读、尺寸和范围外／全白保护区差异均为 0。保存并重开 UI，核对 API 参数与最终 SaveImage 确实执行。改预算、模式、模型或采样后重新配对，不沿用旧效果结论；用执行事件区分真实采样、模型热态与结果缓存。

像素保护的基线是**工作流实际加载得到的原图像素**。曾有 `.png` 文件实际为 JPEG，ComfyUI 0.37.0 的 PyAV 解码与本地 Pillow 解码不同；若直接与本地解码比较，会误判大量范围外变化。可单独保存 LoadImage 输出作为基线；这不等于源文件字节或任意解码器 RGB 均不变。
